# 大なり小なり / SWIPE TEN

スマホの縦画面向けの計算スワイプゲーム。`index.html` をブラウザーで開くと遊べます。依存パッケージやビルドは不要で、外部への通信もありません。

## 遊び方

1. 目標正解数（10問 / 25問）を選んでスタート。
2. 3秒のカウントダウン後、足し算・引き算・掛け算が上から流れます。
3. 答えが **10以上（10を含む）なら右**、**10未満なら左**へスワイプ。
4. 目標正解数に達した瞬間のタイムが結果になります。

左右ボタンやパソコンの矢印キーでも操作できます。不正解や見逃しでは正解数が増えず、次の問題に進みます。負の数・割り算は出題しません。式は一枚ずつ流れ、約5.4秒で下端に達します。

カウントダウンと一時停止中はタイムに含めず、問題間の待ち時間は含めます。別タブや別アプリに移ったときは自動停止。ベストタイムは問題数ごとにこのブラウザーだけに保存し、端末間の同期はありません。効果音は初期状態でオフです。

スマホから遊ぶには、このフォルダーのHTML/CSS/JSを静的Webホスティングへ配置してURLを開いてください。公開・デプロイはまだ行っていません。

## ファイル

- `index.html` / `style.css`: 縦画面UI
- `engine.js`: 出題・正誤判定・進捗
- `app.js`: スワイプ・タイマー・保存
- `engine.test.cjs`: Node.js標準テスト（`node --test engine.test.cjs`）
